WWMAA V10 - NOTIFICATIONS, DOJO MANAGEMENT & MANUAL FEES

NEW FEATURES
1. Notification bell in the top bar lists announcements targeted to the signed-in role and dojo. Click a notice or View all to open Announcements.
2. Dojo management includes name, location, instructor, supported disciplines and editable weekly class schedule. Dojo records save to browser local storage.
3. Announcements can target All members, Students, Senpais, Senseis, Administrators, A Level, B Level and a specific dojo.
4. Voice announcement: admins can preview the announcement aloud, and members can click Listen to announcement. This uses the browser's text-to-speech API; it is not a live voice chat/call and browser voice availability varies.
5. Fees are a manual ledger only. New fee entries start as Due; admins can mark them Paid, Due, Unpaid or Waived, and sort by status, member, amount or month. No online payments are processed.

RUN
Open this folder in VS Code, then run npm install and npm run dev.

LIMITATIONS
This is a browser-local prototype. Notifications, dojo schedules, announcements and fee records do not synchronize between users/devices. Browser text-to-speech speaks on the current device. Production use requires secure authentication, a shared database and server-enforced role permissions.
