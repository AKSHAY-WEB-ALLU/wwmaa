WWMAA V12 Android APK setup

The landing page expects the signed Android WebReader APK at:
public/downloads/wwmaa-webreader.apk

Create the folder public/downloads and place the final signed APK at that exact path before deploying to Vercel. The APK binary was not included with the source files provided for this update, so the Android download button will not deliver an APK until you add it.

For iPhone/iPad, Android APK files cannot be installed. The landing page opens /worldwidemartalart and provides Safari > Share > Add to Home Screen instructions. This creates a web app shortcut; it is not an App Store IPA.

V13.01: The supplied Android WebReader APK is included at public/downloads/wwmaa-webreader.apk. Deploy the project to Vercel and verify the download link after deployment.
