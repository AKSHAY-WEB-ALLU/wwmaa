WWMAA V7 — DOJO-BASED ATTENDANCE

What's new:
- Attendance is recorded separately for each dojo, date, and discipline (Karate / Kick boxing).
- Choose a dojo and training date, then mark each assigned member Present, Absent, or Late.
- To correct old attendance, select the old date and dojo. If a saved session exists, its statuses load; make corrections and click Save attendance.
- The Previous Attendance Records table shows counts and has an Edit action to load an earlier session.
- Student/member attendance pages show the records for that member and their assigned dojo.
- Attendance records are saved in this browser's localStorage, so they remain in the same browser on this device.

Important limitations:
This is a frontend demo, not a shared online attendance database. Records do not sync between devices or users. Browser data can be cleared. Public deployment needs a database (such as Supabase) and server-side authorization, plus an audit trail for attendance corrections.

Run:
1. Extract the ZIP.
2. Open a terminal in this folder.
3. Run: npm install
4. Run: npm run dev
