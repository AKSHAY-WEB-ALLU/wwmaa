WWMAA USER ACCOUNT GUIDE

Use the A Level Control Panel to create, edit, disable, and delete member accounts.
When creating an account, set a unique Login ID and an initial password of at least 6 characters. The form blocks account creation if the initial password is missing. The new account can then use the Student / Senpai / Sensei login tab with that ID and password.

Important limitation: this version stores account records in browser localStorage. It works only in the same browser profile/device where the account was created; it does not synchronize to other devices. The current client-side authentication is not secure enough for real sensitive data. For a public production portal, migrate sign-in and account administration to Supabase Auth with server-side role checks before using real member data.
